## About

This Laravel app is for appointment booking app with doctors. It allows patients to book appointments with healthcare professionals. This app uses Jitsi for video consultations.

- /client/register - Client registration endpoint
- /professional/onboarding - Professional onboarding endpoint
- /professionals - List all professionals
- /client/login - Client login endpoint
- /client/dashboard - Client dashboard endpoint
- /client/appointments - Client appointments endpoint
- /client/appointments/{id} - Get appointment details
- /appointments/{id}/jitsi - Get Jitsi meeting link
